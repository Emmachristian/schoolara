Sale Workflow
1. DRAFT: Create sale and add items
Initial status, can be edited
2. PENDING: Awaiting payment
Invoice created if enabled
3. PAID: Payment received
Journal entry created if enabled
4. ISSUED: Items given to student
Stock updated, transaction complete
Important Notes

Return date must be after sale date
