Override Rules
  • Set at most one override — the server enforces this
  • % override — flat rate, replaces policy entirely
  • Fixed override — hard cap, replaces policy entirely
  • Category matrix — CATEGORY_MATRIX policies only; unlisted categories use policy matrix
  • Tier cap — TIERED policies only; tier logic still runs but result is capped
Important Notes
  • Award is active from start date immediately
  • Auto-apply policies apply at invoice generation
  • Manual policies must be applied per invoice
  • Set end date to match the academic year end
  • Tier context only needed for tiered policies
